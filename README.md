# gmlex

Sito web dello Studio Legale Mannino (Avv. Manlio Mannino, Palermo).

Sito statico a pagina unica, senza dipendenze né cookie:

- `index.html` – contenuti (Studio, Aree di attività, Clienti, Contatti)
- `assets/style.css` – stile
- `assets/favicon.svg` – icona

Per vederlo in locale basta aprire `index.html` nel browser.
Per pubblicarlo è sufficiente GitHub Pages (Settings → Pages → branch, cartella `/`).
